# Y3D-INEX Portfolio

Static HTML/CSS/JavaScript portfolio for Yudhanto Hendra P., ST — Yudha 3D Design — Interior Exterior.

## Deploy
This project has no npm/build requirement. Upload the files to GitHub and import the repository into Vercel with:
- Framework / Application Preset: Other
- Root Directory: ./
- Build Command: empty
- Output Directory: empty

## Edit contact
Open `index.html` and replace:
- `YOUR_EMAIL@example.com`
- `YOURNUMBER`

The Instagram link is set to `https://instagram.com/y3d.inex`.

## Project images
The project images are based on the user's supplied 2025 portfolio pages and can be replaced in `assets/`.
