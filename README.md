# Y3D-INEX Portfolio Website

Static portfolio website for **YUDHA 3D DESIGN — INTERIOR EXTERIOR**, built with plain HTML, CSS and JavaScript. It needs no npm, no build step and no paid service.

## Included
- Premium architecture portfolio homepage
- 11 projects based on the supplied CV + Portfolio 2025
- Architecture / Interior / 3D Visualization filters
- Project detail modal
- About, Services and Contact sections
- Responsive desktop / tablet / mobile layout
- Local project images extracted from the supplied portfolio PDF

## Run locally
Just double-click `index.html`, or use a simple local server if your browser blocks local assets.

## Deploy to GitHub + Vercel
1. Create a new GitHub repository, for example `y3d-inex-portfolio`.
2. Upload **all files and the `assets` folder** from this package.
3. In Vercel, choose **Add New Project** and import the GitHub repository.
4. For this static site, Vercel can deploy it without a build command.
5. Deploy. Vercel will give you a free `*.vercel.app` address.

## Updating project images
Replace the corresponding JPG files in `assets/` while keeping the same filename, or edit the `image` field in `index.html`'s `window.PROJECTS` data.
